    How it works

    1. Add a task — type what you need to do, pick a priority and an optional due date, then press Add.
    2. It remembers for you — every task is saved to The Factory's permanent cloud store, so it stays here between visits and across devices. Watch for the Saved note when it writes.
    3. Tick things off — click the box to mark a task done; filter by All, Active or Done, or search by word.
    4. Clear what's finished — use the × on any task to remove it for good.
